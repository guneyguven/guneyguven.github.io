# Blog text inbox

Upload each article as a separate UTF-8 .txt file in this folder.

- First non-empty line: article title.
- Remaining lines: article body.
- Use the file name for the URL slug, e.g. ai-and-organizational-blindness.txt.
- While the blog is being developed, upload files to the features/blog branch.
- GitHub Actions generates the blog listing and individual HTML pages automatically.

The source text files are retained in this folder.

When ready, upload the article .txt file directly through GitHub's web interface on the feature branch.
